# AI and software engineering

[← Profile overview](./README.md) · [Embedded & Robotics →](./EMBEDDED.md)

I build AI and software systems that are useful beyond a model demo: they have
clear interfaces, observable failure modes, repeatable data flows, and a
validation boundary where an automated action needs one.

## Selected work

| Project | Focus |
|---|---|
| [**Agent-Q**](https://github.com/Kamalbura/agent-q) | Windows accessibility overlay that captures screen context, plans actions through an LLM adapter, and validates them before execution. |
| [**Air Quality Forecasting**](https://github.com/Kamalbura/air-quality-forecasting) | Forecasting platform with Open-Meteo ingestion, PostgreSQL, per-city Airflow DAGs, model selection and tuning, and a Next.js dashboard. |
| [**Smart Car**](https://github.com/Kamalbura/smart_car) | Voice, language, vision, and orchestration services running on a Raspberry Pi and communicating with a dedicated motion controller. |
| [**Air Quality Monitoring**](https://github.com/Kamalbura/Air-quality-monitoring) | ESP32 telemetry, ThingSpeak, Node/Express dashboard, Python analytics, and local CSV fallback. |

## Areas of focus

- Python, TypeScript, C#, SQL, and service-oriented design
- LLM applications, agent workflows, tool integration, and action validation
- Machine learning with PyTorch, XGBoost, scikit-learn, and Optuna
- Data engineering with PostgreSQL, Airflow, Docker, and incremental pipelines
- Web applications with Next.js, React, Node.js, and API-backed interfaces

## Engineering approach

AI systems need the same discipline as any other production system: explicit
inputs and outputs, bounded failure behaviour, measurable performance, and a
clear owner for every action that affects users or devices.
